# ROOTED Evergreen v2 — Visual Source Intake

## Purpose
Drop verified high-resolution originals here for the RC1 → RC2 visual migration.

## Non-negotiable rules
1. Factual scenes use documentary originals only. Do not use generated replacements.
2. Do not extract/capture images from the printed PDF or Word pages.
3. Use the original image file whenever possible.
4. The same original photograph may appear only once in the digital storybook.
   Cropping, mirroring, color correction, resizing, or filename changes still count as the same original.
5. Minimum final crop: 1920×1080. Preferred master: 2560×1440 or higher.
6. Keep KR/EN/RU on one shared visual master.
7. World Bank-specific visit imagery is not part of the Evergreen core.

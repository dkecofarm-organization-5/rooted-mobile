- PC판과 동일한 Scene 구조
- 좌우 split / 이미지 위치 / 본문 위치 유지
- 모바일 전용 본문 재배치 제거
- 가로 화면 기준
- KR / EN / RU 94 Scene 유지
- BGM 및 이미지 자산 로컬 포함

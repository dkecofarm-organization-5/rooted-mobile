# ROOTED Evergreen Digital Storybook v2.0 — BGM FINAL CANDIDATE

## Release scope
This build intentionally excludes narration/voice.

Included:
- KR / EN / RU text editions
- 94-scene Evergreen visual master
- BGM system
- READ / EXPERIENCE modes
- previous / next scene controls
- language switching
- volume / mute controls
- full-screen browser runtime
- final Passing Hope hero
- continuous closing BGM loop behavior

Excluded by editorial decision:
- Korean narration
- English narration
- Russian narration
- any TTS/voice assets or narration timing layer

Voice production is deferred to a separate future project so this release is not blocked by voice-naturalness quality.

## Release status
This is a **FINAL CANDIDATE**, not the Windows FINAL RELEASE.

The remaining release gate is physical Windows acceptance:
1. launcher start,
2. local server start,
3. full-screen browser behavior,
4. KR/EN/RU language switching,
5. BGM output through the target speaker,
6. pause / resume / previous / next,
7. complete loop through Passing Hope → Final Resolution,
8. long-run stability.

Static/browser QA from the prior RC5.1 candidate remains the baseline.

# ROOTED Vol.1 KR / EN / RU Integrated Exhibition Player v1.0

## Scope
This package integrates the approved exhibition editions for:
- KR
- EN
- RU

## Source bases
- Integrated player baseline: `ROOTED_Vol1_KR_EN_INTEGRATED_EXHIBITION_PLAYER_v1.4_FINAL_BRANDED`
- RU runtime baseline: `ROOTED_Vol1_Digital_Storybook_RU_LANDSCAPE_EXHIBITION_SHORT_v1.1.3_EDITORIAL_TYPO_FINAL`

## Key behavior
- fixed header with DK EcoFarm logo and FarmTOS-ON logo
- language switch available at all times: `KR | EN | RU`
- continuous playback
- pause / restart / stop / fullscreen controls
- language switch stops the previous language and restarts the selected language from scene 1
- Journey 2 and Journey 3 remain fully preserved in all three languages

## Start
Double-click:
`START_ROOTED_KR_EN_RU_EXHIBITION.bat`

## If needed
- reset runtime state: `RESET_ROOTED_KR_EN_RU_RUNTIME.cmd`
- diagnostic launch: `START_ROOTED_KR_EN_RU_DIAGNOSTIC.cmd`
